# Keyboard shortcuts

## Files

| Shortcut | Command |
|---|---|
| <kbd>⌘</kbd><kbd>N</kbd> | File ▸ New Deck… |
| <kbd>⌘</kbd><kbd>O</kbd> | File ▸ Open Deck or Project… |
| <kbd>⌘</kbd><kbd>S</kbd> | File ▸ Save to Original |
| <kbd>⌘</kbd><kbd>W</kbd> | File ▸ Close Window |
| <kbd>⌘</kbd><kbd>Q</kbd> | Manimble ▸ Quit Manimble |

## Editing

| Shortcut | Command |
|---|---|
| <kbd>⌘</kbd><kbd>Z</kbd> | Undo |
| <kbd>⇧</kbd><kbd>⌘</kbd><kbd>Z</kbd> | Redo |
| <kbd>⌘</kbd><kbd>X</kbd> / <kbd>⌘</kbd><kbd>C</kbd> / <kbd>⌘</kbd><kbd>V</kbd> | Cut / Copy / Paste |
| <kbd>⌘</kbd><kbd>A</kbd> | Select all text in a text box; right after moving an object in one build, apply the move to every build |
| <kbd>⌘</kbd><kbd>F</kbd> | Find… |
| <kbd>⌥</kbd><kbd>⌘</kbd><kbd>F</kbd> | Find and Replace… |

## On the canvas

| Shortcut | Action |
|---|---|
| Arrow keys | Nudge the selection |
| <kbd>⇧</kbd> + arrow keys | Nudge in bigger steps |
| <kbd>↩</kbd> | Edit the selected object's text or formula |
| <kbd>⌫</kbd> | Delete the selection |
| <kbd>Esc</kbd> | Deselect; put away a drawing tool |
| <kbd>⇧</kbd>-click | Add to the selection |
| <kbd>⇧</kbd> while dragging | Move only horizontally or vertically; snap a line's angle; draw a square or circle |
| <kbd>⌥</kbd> while dragging | Move without snapping |
| <kbd>⌘</kbd> while dragging a line end | Place the end without attaching it to an object |

## In a text box

| Shortcut | Action |
|---|---|
| <kbd>↩</kbd> | New line |
| <kbd>⌘</kbd><kbd>↩</kbd> | Apply |
| <kbd>Esc</kbd> | Discard the change |
| <kbd>⇥</kbd> | Next table cell |

## Play

| Shortcut | Command |
|---|---|
| <kbd>⌥</kbd><kbd>⌘</kbd><kbd>A</kbd> | Show Animations (on or off) |
| <kbd>⌥</kbd><kbd>⇧</kbd><kbd>⌘</kbd><kbd>P</kbd> | Play from Beginning |
| <kbd>⌥</kbd><kbd>⌘</kbd><kbd>P</kbd> | Play from Current Slide |
| <kbd>⌃</kbd><kbd>⌘</kbd><kbd>P</kbd> | Presenter View |
| <kbd>⌥</kbd><kbd>⌘</kbd><kbd>R</kbd> | Preview Current Slide's Animations |

The keys that work during a show are listed in [Playing a presentation](../presenting/playing.md#keys-during-a-show).
In Presenter View, <kbd>R</kbd> resets the timer (instead of replaying the build) and <kbd>F</kbd> turns Feedback
Mode on and off.
